# Appears brand

Appears has its own identity. Don't borrow from whosaid or heade.rs (Geist, hairline-blue, Liquid Glass capsules).

- **Idea:** things surfacing into view. The mark is a ring (what you're looking at) with a dot rising at its top edge (something you already had).
- **Menu bar glyph** (drawn in code, `mac/App/Sources/Glyph.swift`): ring = idle; ring with a gap = indexing; ring + filled dot = something's here. Template images, so they work in any menu bar.
- **Colour:**
  - paper `#F4F1EA`, ink `#17150F`, muted `#6B655A`, rule `#DCD6CA`;
  - signal (the only accent) `#E0531F`;
  - dark: paper `#121110`, ink `#EDE8DE`, muted `#9A9387`, rule `#2A2723`, signal `#FF6A33`.
- **Type:** an editorial serif for display (Instrument Serif on the site), a quiet grotesk for text. The app uses the system font.
- **Voice:** calm, plain, a little warm. Never "AI-powered", never exclamation marks.
